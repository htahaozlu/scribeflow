# 04 — Conventions, Packaging & Publishing

> Mirror the owner's sibling project [`context-bar`](https://github.com/htahaozlu/context-bar)
> conventions, **adapted to Python** (context-bar is Rust+Swift; ScribeFlow is pure Python). Goal: the new
> repo feels like a sibling — same license, bilingual docs, badge style, commit discipline,
> governance, "minimal but crafted" aesthetic.

## 1. Naming

- Pattern from context-bar: short, evocative, kebab-case package + CamelCase/display name.
- **Display:** `ScribeFlow` · **package / CLI / PyPI:** `scribeflow` (ASCII). One constant `scribeflow.__about__`.
- Treat the name as a single find-replace token across the codebase (doc 00).

## 2. License — **Apache-2.0**

context-bar is Apache-2.0. Match it. Full `LICENSE` text + `pyproject.toml` `license = "Apache-2.0"`
+ SPDX badge `license-Apache--2.0`. (GitHub may misdetect; keep the file canonical.)

## 3. README — bilingual, centered-HTML header

- **Two files:** `README.md` (English) + `README.tr.md` (Turkish), with a header switcher `English | Türkçe`.
- The CLI itself is bilingual (`--lang en|tr`, locale default) — ship EN+TR strings.
- Header block (centered HTML, `<p align="center">`): **logo → lang switcher → bold one-line tagline → blurb → install/CTA → flat-square brand-colored badges → platform badges**.
- Section order (adapt context-bar's): **Demo GIF → Install → Quickstart → What it does → Backends & hardware → Usage (CLI verbs/flags) → Web UI → Colab → Output formats → How resume works → Config → Contributing**.
- Tone: confident, precise, honest. State limits plainly ("local models, no cloud in v1", "Apple GPU via whisper.cpp", "transcripts are best-effort ASR, not verbatim legal records").

## 4. Packaging (Python — D2: pip/PyPI)

- **`pyproject.toml`** (PEP 621), build backend `hatchling` or `setuptools`. Single source layout `src/scribeflow/`.
- **Console entry point:** `scribeflow = "scribeflow.cli:main"`. Optional short alias documented, not duplicated.
- **Optional extras** (keep base install tiny — base = engine + faster-whisper):
  - `[gpu]` torch+CUDA notes (document, don't hard-pin), `[cpp]` pywhispercpp / build helper,
    `[openai]` openai-whisper, `[web]` fastapi+uvicorn+jinja/htmx, `[url]` yt-dlp, `[drive]` Drive API/mount helpers, `[dev]` pytest+ruff+mypy.
- **System dep:** ffmpeg (document install per OS; preflight check via `ensure_ffmpeg`).
- **`.gitignore`:** `dist/`, `*.zip`, `.idea/`, `__pycache__/`, media dirs, model caches, `.venv/`.
  (Old repo committed `.idea/` and large zips — do NOT carry that over.)

## 5. Conventional Commits (scoped, lowercase, no period)

Match context-bar: `feat(cli):`, `fix(engine):`, `docs(readme):`, `chore(release):`, `ci(publish):`,
`perf(chunking):`, `test(checkpoint):`. Scopes map to subsystems: `engine`, `backends`, `sources`,
`targets`, `cli`, `web`, `notebook`, `devices`, `policy`, `config`, `ci`, `docs`.

> Repo-owner override (their global rule): **subject-only, ≤72 chars, no body, no attribution,
> never amend unless asked.** Honor this — it's compatible with scoped one-liners. Do not add
> Co-Authored-By / "Generated with" trailers.

## 6. Governance / community files (context-bar ships the full set)

`CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`, `CHANGELOG.md` (Keep-a-Changelog),
`.github/PULL_REQUEST_TEMPLATE.md`, `.github/ISSUE_TEMPLATE/{bug_report,feature_request,config_help}.yml` + `config.yml`,
`.github/FUNDING.yml` (`github: [htahaozlu]`), `.github/release.yml`.

## 7. Docs layout

`docs/ai/` (these design docs — keep, they document intent), `docs/images/` (logo, demo GIF, screenshots),
`docs/PUBLISHING.md`, `docs/RELEASING.md`, `docs/CONFIG.md`. Demo GIF generated by a committed script
(context-bar pattern: repeatable, not ad-hoc).

## 8. Release / CI (SemVer tags, bot-driven)

- **SemVer git tags** `vX.Y.Z`. CI-driven releases (GitHub Actions), not manual.
- Two workflows (mirror context-bar's split):
  - `release.yml` — on tag: build sdist+wheel, run tests, create GitHub Release with notes.
  - `publish.yml` — **idempotent** PyPI publish (tolerate "already uploaded"); trusted publishing (OIDC) preferred over API token.
- Optional: matrix test (Linux/macOS, py3.10–3.12), `ruff` + `mypy` + `pytest` gates on PR.
- Badges: PyPI version, Python versions, license, CI status, downloads — flat-square, brand colors
  (context-bar palette: release blue `#2F81F7`, accent green `#7DCEA0`).

## 9. Aesthetic checklist ("sade ama sanatsal")

- One accent color, lots of whitespace, tasteful monospace for CLI snippets.
- Logo (`docs/images/logo.png`), animated **demo GIF** of a transcription run (CLI + web).
- Web UI: single calm page; live progress bar fed by `progress.json`; subtle motion only.
- A "share card" style screenshot for the README header (context-bar does this).
- No ASCII-art clutter; polish via clean type + one good GIF (context-bar's "artistic" signal is craft, not decoration).
